# Home — household, school, kids

A starter project for running your household with AI agents helping you stay on top of the moving parts.

This template assumes a family with school-aged kids. Adapt freely.

## What's in this template

| Directory | What lives here | Agent role |
|---|---|---|
| `family-admin/` | Calendar, appointments, reminders, the catch-all inbox | The household secretary |
| `school-coordinator/` | School timetable, term dates, homework tracker, permission slips, parent-teacher comms | School-life manager |
| `finances/` | Household budget, bills, recurring subscriptions, savings goals | Family CFO |
| `kids-activities/` | After-school activities, sports, music, birthday parties, friend logistics | Kids' calendar wrangler |
| `meal-planning/` | Weekly meal plan, shopping lists, dietary preferences, recipes | Meal planner |

## Suggested first steps

1. Open `family-admin/README.md` — that agent is the most useful first hire. Tell it your family members, key dates (birthdays, school terms, holidays), recurring obligations.
2. Spawn the agent in `family-admin/` from the project page.
3. Chat with it: "Here's our family calendar for the next 4 weeks." Let it organise.
4. Once `family-admin` is humming, spawn `finances/` and have it ingest your bills/recurring payments.
5. Add the other lanes as needed. You don't have to spawn all of them.

## Privacy

This is your private repo on GitHub under the `2hives-ai` org. Treat it like your filing cabinet:

- **Do** store schedules, todo lists, shopping lists, recipes, notes about kids' interests.
- **Don't** paste passwords, bank account numbers, full credit card details, government IDs (driver's license, passport, Medicare). Use your password manager for those — share with the agent only the reference it needs ("the gas bill is in 1Password item Gas-Bill-2026").
- The repo is private but it's still version-controlled — anything you check in stays in history.

## Customising

You're encouraged to:

- Delete directories you won't use (e.g. `meal-planning/` if you have it covered).
- Add new ones (e.g. `pets/`, `garden/`, `home-maintenance/`, `extended-family/`).
- Rewrite the per-directory `README.md` to match how YOU work. The agent reads its `README.md` on startup, so the agent's effectiveness scales with how clear that file is.

## Tier limits

Basic tier: 1 active project + 2 concurrent agents. Upgrade for unlimited if you want all 5 agents running at once.
